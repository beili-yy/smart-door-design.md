# 智能入户门屏端设计规范

供 AI agent 和开发同事使用的完整设计规范文档。

## 包含内容

- 双屏硬件参数（前屏15.6寸 / 后屏7寸）
- 色彩/字体/圆角/间距 Token
- 16个组件规范（Button/Navigation/Cell/Dialog等）
- 115个图标清单（含 Figma Node ID，可导出SVG）
- 9种页面类型精确布局模板
- AI 生成检查清单

## 关联仓库

- [SVG图标库](https://github.com/beili-yy/smartdoor_icon) — 115个导出的SVG图标

## AI 使用方式

将 `smart-door-design.md` 作为上下文传给大模型即可生成符合规范的页面。
