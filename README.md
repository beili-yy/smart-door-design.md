# 智能入户门屏端设计规范

宝思派（BSP）智能入户门双屏产品的 UI 设计规范文档，涵盖色彩、字体、圆角、组件、图标、布局等设计系统定义。

## 文档内容

- 双屏硬件参数（前屏/内屏 15.6寸 1080×1920，后屏/外屏 7寸 600×1024）
- 色彩系统（Primary/Neutral/NV/语义色/安全等级色）
- 字体系统（Source Han Sans CN + Roboto + Noto Sans SC）
- 圆角/间距 Token
- 16 个组件规范（Button/Navigation/SideBar/Cell/Dialog/Input/Toast/Alert/Switch 等）
- 115 个图标清单（含 Figma Node ID，可导出 SVG）
- 9 种页面类型精确布局模板（A首页型/B设置型/C列表型/D全屏型/E录入型/F结果型/G键盘型/H待机型/I锁定型）
- AI 生成检查清单与速查表
